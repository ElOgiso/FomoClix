# FomoClix - Multi-chain Agentic AI Trading OS

FomoClix is a production-grade multi-chain agentic trading bot platform operating across Zora, Solana, and Base networks.

## Repository Structure

- `frontend/`: Compiled React & Vite user interface with real-time WebSockets and customized non-robotic natural speech synthesis.
- `backend/`: Node.js Express server running the trading engine, strategy engine, market intelligence module, memory manager, and LLM orchestration layer.

## Setup & Running

Refer to the README and guide documents in `frontend/` and `backend/` subfolders for setup instructions.
