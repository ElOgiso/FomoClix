# DigitalOcean Deployment Guide - V1 Zora/Base Bot

This guide outlines the production deployment of the V1 Zora/Base Trading Bot on a DigitalOcean Droplet (Ubuntu).

---

## Architecture Overview

* **Frontend:** Compiled React/Vite assets served statically via **Nginx**.
* **Backend:** Express API server run in the background via **PM2** on port `8080`.
* **Database:** Local **SQLite** database (`bot.db`) created and maintained inside the backend directory.
* **Routing:** Nginx acts as a reverse proxy, serving the static frontend files directly and proxying API endpoints (such as `/status`, `/trades`, `/bot/*`, etc.) to the Express server.

---

## Step 1: Provision the Droplet
Create a new Droplet on DigitalOcean:
* **OS:** Ubuntu 22.04 LTS or 24.04 LTS
* **Plan:** Basic (1 vCPU, 1GB RAM or 2GB RAM is sufficient)
* **SSH Key:** Set up your SSH key for secure access.

---

## Step 2: Install Server Dependencies
Once connected via SSH (`ssh root@your_droplet_ip`), run the following commands to install system dependencies:

```bash
# Update package lists
sudo apt update && sudo apt upgrade -y

# Install Node.js (v20 LTS) & npm
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Install PM2 globally
sudo npm install -y pm2 -g

# Install Nginx
sudo apt install -y nginx

# Install SQLite3 system client (optional for CLI debug)
sudo apt install -y sqlite3
```

---

## Step 3: Configure Directories & Transfer Code
1. Create directories for frontend and backend on the droplet:
   ```bash
   sudo mkdir -p /var/www/zora-trading-bot
   sudo mkdir -p /var/www/zora-bot-service
   sudo chown -R $USER:$USER /var/www
   ```

2. Transfer files to the Droplet. You can upload the projects using `scp`, `sftp`, or a Git repository.
   * **Frontend code** goes to `/var/www/zora-trading-bot`
   * **Backend code** goes to `/var/www/zora-bot-service`

---

## Step 4: Configure and Build Frontend
1. Navigate to the frontend directory:
   ```bash
   cd /var/www/zora-trading-bot
   ```
2. Configure `.env` file for Vite production build:
   Create a `.env` file:
   ```bash
   nano .env
   ```
   Add the following line (since we are reverse-proxying from the same domain, keep it relative):
   ```ini
   VITE_API_BASE_URL=
   ```
3. Install dependencies and compile the production build:
   ```bash
   npm install
   npm run build
   ```
   This generates the static files in `/var/www/zora-trading-bot/dist/`.

---

## Step 5: Configure and Start Backend
1. Navigate to the backend directory:
   ```bash
   cd /var/www/zora-bot-service
   ```
2. Create and configure the `.env` production file:
   ```bash
   cp .env.production.example .env
   nano .env
   ```
   Provide the actual production secrets:
   * `PRIVATE_KEY` (The trading wallet private key)
   * `ALCHEMY_RPC_URL` (Alchemy RPC URL for Base network)
   * `NEYNAR_API_KEY` (Farcaster/Neynar API key for social signals)
   * `NEYNAR_WEBHOOK_SECRET` (For verifying Neynar webhooks)
   * `CORS_ALLOWED_ORIGIN` (Your server's domain/IP)

3. Install production dependencies:
   ```bash
   npm install --omit=dev
   ```

4. Start the backend process using PM2:
   ```bash
   pm2 start ecosystem.config.js --env production
   ```
   *Note: PM2 will automatically load the configuration and execute `node index.js` under the process name `zora-bot-service` on port `8080`.*

5. Save PM2 state so it restarts on system reboots:
   ```bash
   pm2 save
   pm2 startup
   ```
   *(Run the script generated by the output of `pm2 startup`.)*

---

## Step 6: Configure Nginx Reverse Proxy
1. Delete default Nginx site configuration:
   ```bash
   sudo rm /etc/nginx/sites-enabled/default
   ```
2. Create your site configuration using the provided example:
   ```bash
   sudo nano /etc/nginx/sites-available/zora-trading-bot
   ```
   Paste the configuration from `nginx.conf.example` and change `your-domain.com` to your domain or server IP.

3. Enable the configuration and restart Nginx:
   ```bash
   sudo ln -s /etc/nginx/sites-available/zora-trading-bot /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemcctl restart nginx
   ```

---

## Step 7: Secure with SSL (Let's Encrypt Certbot)
To obtain free SSL certificates and automatically configure HTTPS:
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```
Follow the interactive prompt to complete SSL generation. Certbot will update your Nginx configuration to support HTTPS.
